# Releasing actdbg

Binary releases and the Homebrew formula are produced by [GoReleaser](https://goreleaser.com)
on every `v*` tag (`.github/workflows/release.yml` + `.goreleaser.yaml`).

## One-time setup (do this once)

1. **Create the tap repo.** On GitHub, create an empty public repo named
   `homebrew-actdbg` under your account:
   ```
   gh repo create Socialpranker/homebrew-actdbg --public \
     --description "Homebrew tap for actdbg"
   ```
   (The `homebrew-` prefix is required by Homebrew; users then run
   `brew install Socialpranker/actdbg/actdbg`.)

2. **Create a PAT for the tap.** GoReleaser needs to push the generated formula
   to the tap repo, which the default `GITHUB_TOKEN` can't reach.
   - GitHub → Settings → Developer settings → Personal access tokens →
     Fine-grained token with **Contents: read/write** on `homebrew-actdbg`
     (or a classic token with `repo` scope).
   - On the **actdbg** repo: Settings → Secrets and variables → Actions →
     New repository secret → name `TAP_GITHUB_TOKEN`, paste the token.

3. **(Optional) Validate the config locally** without publishing:
   ```
   brew install goreleaser   # or: go install github.com/goreleaser/goreleaser/v2@latest
   goreleaser check
   goreleaser release --snapshot --clean   # builds into ./dist, publishes nothing
   ```

## Cutting a release

```
git tag v0.4.1          # bump as appropriate
git push origin v0.4.1
```

The `release` workflow then:
- builds `linux`/`darwin` × `amd64`/`arm64` binaries,
- creates a GitHub Release with archives + `checksums.txt` + autogenerated notes,
- updates the Homebrew formula in `Socialpranker/homebrew-actdbg`.

After the first successful release, users can:
```
brew install Socialpranker/actdbg/actdbg
# or, without the tap shorthand:
brew tap Socialpranker/actdbg && brew install actdbg
```

## Notes

- Windows is intentionally not built — actdbg drives Docker via act and targets
  Linux/macOS hosts.
- `main.version` is injected at build time via ldflags, so `actdbg version`
  reports the released tag.
- If the Homebrew step fails (missing/expired `TAP_GITHUB_TOKEN`), the binary
  release still succeeds — fix the token and re-run the failed job, or push a
  new patch tag.
